# English teacher — On Air English

Две версии разговорных уроков английского:

| | Веб-приложение `docs/` | Артефакт в Claude `dist/` |
|---|---|---|
| Где | GitHub Pages, ставится на экран «Домой» | https://claude.ai/artifact/GBvpCYnngvFhNVBwN2YCLk |
| Голос | микрофон приложения, без клавиатуры | диктовка с клавиатуры телефона |
| Фразы вслух | проверка разборчивости: какие слова распознавание не разобрало | нет |

| Прогресс | в браузере + резервная копия в файл | на сервере артефакта |

## Веб-приложение

Адрес: https://paakucabariu.github.io/English-teacher/ — публикуется из `docs/` workflow `.github/workflows/pages.yml` при каждом изменении в `main`.

1. Открыть адрес в Safari на iPhone → Поделиться → «На экран Домой».
2. Ввести ключ Claude API. Он хранится только на устройстве.

Речь распознаёт браузер (Safari, Chrome). После урока — разбор и экран «Фразы вслух»: образец голосом, ваша попытка, слова, которые распознавание не разобрало, подсвечиваются и копятся на главной. Это проверка разборчивости, а не оценка отдельных звуков.

`docs/vendor/` — собранный `@anthropic-ai/sdk` 0.128.0 (лицензия рядом). `docs/lessons.js` генерируется `build.py` из `src/lessons.js`.

## Артефакт в Claude

## Урок, ~20 минут

Урок ведёт Алекс (Claude), его ответы озвучиваются голосом. Вы отвечаете голосом через микрофон клавиатуры телефона.

1. Разминка — разговор о вашем дне, повтор фраз прошлого урока.
2. Фразы урока — 3 фразы под ваши ошибки, с каждой своё предложение.
3. Разговор — спор на тему урока, ошибки записываются молча.
4. Ситуация — ролевая игра.
5. Работа над ошибками — свои фразы урока заново, уже правильно.

Этапы переключает приложение по таймеру; закончить урок можно только кнопкой «Закончить» (двойное нажатие).

После урока — разбор: оценки, ошибки, фразы, план следующего урока. Прогресс, банк ошибок и история хранятся на сервере артефакта.

## Разбор в Claude Code

Скилл `/english-coach` читает уроки из базы артефакта, делает разбор за несколько уроков и переписывает следующий урок.

## Разработка

- `src/shell.html` — разметка и стили, `src/lessons.js` — этапы и темы, `src/runtime.js` — логика.
- `python3 build.py` собирает `dist/on-air-english.html`, который публикуется как артефакт.
