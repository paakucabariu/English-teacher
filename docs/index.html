Ключи

Ключи хранятся только на этом устройстве и отправляются только в Anthropic и Microsoft.

1. Claude — ведёт урок и делает разбор

  1. console.anthropic.com → API keys → Create key.
  2. В Billing пополните баланс (хватит $5 для старта).

2. Azure Speech — слушает и оценивает произношение

  1. portal.azure.com → создать ресурс Speech, тариф Free F0.
  2. Откройте ресурс → «Keys and Endpoint»: скопируйте KEY 1 и Location/Region.
